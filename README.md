# 🌸 Animated Flower Code

A beautiful animated flower created using **HTML, SCSS, and JavaScript**. This mini-project demonstrates front-end animation techniques to design an elegant blooming flower effect for learning and creative web design purposes. ([GitHub][1])

## ✨ Features

* 🌷 Smooth flower blooming animation
* 🎨 Modern and visually appealing design
* 📱 Responsive layout
* ⚡ Lightweight and fast
* 🖥️ Built using pure HTML, SCSS, and JavaScript

## 🛠️ Technologies Used

* HTML5
* SCSS
* JavaScript

The repository primarily consists of SCSS, HTML, and a small amount of JavaScript. ([GitHub][1])

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Abhijeetx777x/Animated-Flower-Code.git
```

### Open the Project

1. Navigate to the project folder.
2. Open `index.html` in your browser.
3. Enjoy the animated flower! 🌸
